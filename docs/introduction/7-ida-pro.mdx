O IDA é, de modo direto, um dos melhores softwares para análise estática de Engenharia Reversa que existe no mercado. Porém, ele é um software pago.

## Comandos Básicos

- `F5` - Decompilar
- `Tab` - Alterna o foco entre o Disassembler e Decompilador
- `n` - Renomear função/variável/endereço
- `y` - Alterar tipo da função/variável
- `Esc` - Voltar (ao dar 2 cliques em uma função)
- `Ctrl+Enter` - Avançar
- `Espaço` - Altera entre o modo de fluxo gráfico e o modo texto contínuo
- `/` - Adiciona comentário na linha atual (visível no pseudocódigo)

## Outros comandos

- `u` - Remove a interpretação do IDA no local selecionado (retorna aos bytes brutos)
- `r` - Converte para ASCII
- `Shift+F3` - Lista todas as funções do binário
- `Shift+F12` - Lista todas as strings legíveis
- `Shift+F4` - Lista global de símbolos, importações e funções
- `Shift+F1` - Lista de structs e definições de tipo do projeto
