# CatchThe Fox

Olá, seja bem vindo! Este é um site de artigos, construído com o intuito de auxiliar nas aulas da frente de Engenharia Reversa/Pwning do grupo Ganesh-ICMC.

## Contribuindo para o projeto

Os artigos se encontram na pasta `docs`, e estão em formato `md` ou `mdx`. Caso queira fazer alguma correção, o artigo se encontrará no mesmo caminho que está no site (Ex: https://ariiialves.github.io/manual-pwning/pwning/1-1-protections -> Artigo estará em docs/pwning/1-1-protections). Você pode fazer um Pull Request, ou criar uma Issue com o label `invalid`, para facilitar a identificação.

Nota: Para um artigo aparecer indexado no site, ele tem que ser inserido em [sidebars.js](./sidebars.js). Basta colocar o novo caminho em `items`, na ordem desejada.

Para escrever um novo artigo, você pode abrir uma Issue e escrever o artigo em Markdown. Coloque o label `documentation`, para facilitar a identificação. Você pode também fazer um Pull Request.

## Rodando projeto localmente

Esse site foi construído utilizando [Docusaurus](https://docusaurus.io/). Para rodar localmente, clone o repositório e:

- Instale: `npm i docusaurus`
- Rode localmente: `npm run start`
